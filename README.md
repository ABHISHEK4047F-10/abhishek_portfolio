# Portfolio: Abhishek Kumar Agrahari

Single-file site: all HTML, CSS and JS live in `index.html`. No build step.

1. Extract the whole zip first (don't open index.html from inside the zip).
2. Search `index.html` for `your-email@example.com` and put in your real email.
3. Deploy: drag the folder into Netlify Drop, or push to GitHub and enable Pages, or run `vercel`.
4. Keep `resume.pdf` next to `index.html` so the Resume button works.
